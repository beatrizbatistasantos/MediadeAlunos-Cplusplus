# MediadeAlunos-Cplusplus
Uma escola necessita de um sistema para o cálculo da média dos alunos ao longo do ano, uma vez que o cálculo é realizado de forma manual. O algoritmo precisa receber 4 notas bimestrais, mostrar a média e informar se o aluno foi aprovado (caso a média seja maior que 6), ou, senão, “reprovado”.
